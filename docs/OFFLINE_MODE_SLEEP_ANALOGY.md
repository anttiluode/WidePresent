# Offline temporal mode: sleep as inspiration, not mechanism

Date: 2026-08-11

WidePresent recently exposed a failure mode in changing environments: a long boundary trace can contain echoes generated by a world that is no longer current. A wider temporal aperture improves observability only until obsolete evidence contaminates the estimate.

This note asks whether an **input-quiet interval** can support a different processing mode that reduces that interference.

It is deliberately not a theory of biological sleep.

## 1. The useful abstraction

The minimal engineering distinction is:

```text
ONLINE / WAKE-LIKE
    uncontrolled external evidence keeps arriving
    task: react, infer, route, update

OFFLINE / QUIET-LIKE
    external input is reduced or gated
    task can change: decay, replay, compare, probe, compress, re-index
```

The important hypothesis is not "no input is good." It is:

> **When uncontrolled input pauses, the system may profitably switch objectives.**

That objective might be internal replay, controlled system identification, consolidation, provenance repair, or simple relaxation.

## 2. Why the analogy is biologically reasonable but limited

Two recent results motivated the comparison:

- Giri et al., *Nature* (2024), DOI `10.1038/s41586-024-07538-2`, found that sleep deprivation can preserve abundant hippocampal sharp-wave-ripple activity while markedly reducing reactivation and replay. So "lots of activity" is not equivalent to organized offline processing.
- Chang et al., *Nature* (2025), DOI `10.1038/s41586-024-08340-w`, found that sleep microstructure organizes replay of recent and older memories in a way relevant to interference control.

These results do not imply the WidePresent mechanism below. They only license the engineering question: can a change in input regime permit a useful change in temporal processing regime?

## 3. First machine test

`experiments/offline_quiet_probe.py` uses the same general boundary-observability family as the Rajapinta experiments.

A hidden spring graph switches topology at `t=9 s`. The observable boundary stem stays locally identical. The task is to classify the **current** hidden topology from boundary activity over `13.5--18 s`.

Four modes are compared:

1. `continuous`: nuisance external pulses continue;
2. `quiet`: external drive stops at `t=11 s`;
3. `self_probe`: quiet, followed by a standardized internally controlled probe at `t=13.5 s`;
4. `downscale_probe`: same self-probe, but with aggressively increased damping before the probe to erase mixed fast state.

All conditions use the same feature dimensionality and same classifier family.

## 4. Exploratory scratch result

With 150 examples per seed and seeds 0--2, the scratch implementation produced:

| mode | seed 0 | seed 1 | seed 2 |
|---|---:|---:|---:|
| continuous | 0.453 | 0.491 | 0.396 |
| quiet | 0.717 | 0.755 | 0.774 |
| self-probe | 0.792 | 0.830 | 0.736 |
| strong-damping + probe | 0.755 | 0.717 | 0.660 |

Chance is `1/3`.

These are exploratory numbers, not a registered result. The committed experiment is intended to reproduce or kill them.

The useful qualitative outcome is that **quiet alone helped**, and a controlled internal probe often helped further. But deliberately forcing stronger forgetting did not help; it usually hurt.

So the current interpretation is not:

> sleep = erase old state.

It is closer to:

> **quiet reduces uncontrolled interference, creating a cleaner channel for internal operations.**

## 5. Connection to the WidePresent two-clock problem

The changing-world boundary experiment already showed:

```text
arrival time != generation/world time
```

An echo can reach `NOW` after the condition that generated it has ceased to be true.

An offline phase can therefore be viewed as an opportunity to repair temporal provenance:

```text
incoming stream pauses
        |
        v
separate / replay / re-probe / re-tag traces
        |
        v
resume online inference with a cleaner current-state estimate
```

This is potentially more interesting than merely letting a recurrent state decay.

## 6. Sleep as an epoch boundary

A stronger WidePresent interpretation is that a mode change can create an **epoch boundary**.

Instead of treating one indefinitely long history as a homogeneous context, the system can explicitly mark:

```text
epoch A: generated under world/operator A
offline transition
epoch B: generated under world/operator B
```

That is compatible with the bitemporal ledger: evidence has both a world-valid time and a knowledge/arrival time, and a mode transition supplies an additional provenance marker.

This suggests an upcoming test: whether explicit epoch/source tagging solves mixed-echo classification better than either a fixed temporal window or passive decay.

## 7. A more general mode-switch architecture

The sleep analogy suggests adding a discrete mode variable `z(t)` to the otherwise continuous temporal substrate:

```text
z = ONLINE
    external-input gain high
    action/routing objective active
    fast state preserved

z = OFFLINE
    external-input gain low
    controlled replay/probe allowed
    slow-state update/consolidation allowed
    provenance reconstruction allowed
```

This is not necessarily binary. Multiple offline modes could exist, just as ordinary engineered systems have calibration, self-test, idle, update, and active-service states.

The key point is that **the same substrate can compute differently when the input regime changes**.

## 8. What would make this specifically WidePresent-shaped?

The generic idea of offline replay is old. The branch matters only if WidePresent contributes something beyond experience replay or ordinary sleep-inspired continual learning.

The promising differentiator is the combination of:

1. moving objective `now`;
2. boundary observability requiring a finite temporal aperture;
3. stale echoes generated under previous world states;
4. explicit world-time versus arrival-time provenance;
5. an offline mode that repairs or re-estimates that temporal state before returning online.

A concrete claim would be:

> **Offline processing improves current-state estimation specifically by resolving temporal-source ambiguity, not merely by replaying more samples.**

That is testable.

## 9. Next experiments

### A. Provenance tagging versus passive quiet

Attach a generation epoch to each internally simulated probe/echo. Compare:

- no tags;
- fixed recent window;
- passive quiet;
- explicit epoch tags;
- bitemporal world/arrival tags.

If tags beat quiet, the real mechanism is provenance rather than sleep-like mode switching.

### B. Learned trigger for going offline

Do not schedule quiet by hand. Give the controller a cost for being offline and let it decide when expected interference justifies a self-probe/reorganization phase.

### C. Replay versus active probing

Replay old internal traces and compare against injecting known diagnostic probes. These solve different problems:

- replay tests/strengthens retained associations;
- active probing estimates the current substrate.

The distinction matters in nonstationary environments.

### D. Consolidation into slow state

During offline mode, compress the recent wide boundary trace into the slower modulator/ledger, then discard some fast state. Test whether this preserves useful current information without retaining obsolete wave detail.

## 10. Kill conditions

Drop this branch if:

- simple input gating explains every benefit;
- a Kalman/filtering baseline or explicit change-point detector matches it;
- provenance tags eliminate the need for a separate offline mode;
- self-probing helps only because the diagnostic input was hand-designed for the toy topology;
- benefits disappear under unknown/noisy actuation;
- the mode switch adds no value on agent tasks with real asynchronous evidence.

The goal is not to make WidePresent sleep.

It is to ask whether a temporal system should sometimes stop consuming the world in order to **re-establish what time/world its own internal evidence belongs to**.
